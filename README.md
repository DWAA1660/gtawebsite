# GT Aeronautics Modern Website Redesign (v3)

## Overview

This folder contains a fully modernized version of the GT Aeronautics website (v3). The redesign focuses on a responsive, mobile-first experience using modern HTML5, CSS3, and JavaScript, while preserving the original content and branding of the legacy site.

## Directory Structure

- **index.html**: The main landing page.
- **css/**: Stylesheets (main `styles.css`).
- **js/**: JavaScript files for interactivity.
- **images/**: Optimized and renamed assets migrated from the original site.
- **[page].html**: Individual pages for products, services, news, etc.

## Maintenance

- **Updating Content**: Edit the HTML files directly.
- **Adding Images**: Place new images in the `images/` folder.
- **Styles**: Global styles are in `css/styles.css`.
